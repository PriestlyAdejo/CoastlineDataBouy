# Architecture

This directory will hold the canonical system architecture documentation.

## Recommended docs to maintain

- `system-overview.md`: mission, components, runtime responsibilities
- `edge-services.md`: Pi service graph, systemd units, failure behavior
- `protocols.md`: Pi↔Arduino UART protocol, versioning
- `storage-layout.md`: on-SSD paths, retention, index strategy
- `backend-ingest.md`: upload protocol, idempotency, manifests
- `data-contracts.md`: schema catalog and evolution rules
