# Hardware

Verified hardware and wiring notes live here.

## Verified interfaces (v1)

- Pi ↔ Arduino UART at 115200 on Pi GPIO14/15 (via HiFiBerry passthrough)
- DS18B20 on Pi GPIO4 (1-wire)
- HiFiBerry DAC2 ADC Pro capture device for hydrophone audio
- MCP23017 I2C expander at address `0x20`
- External SSD for data storage
