PROJECT CONTEXT
The project is a sensing buoy that collects and displays marine/environmental data from onboard sensors. One major sensor is a hydrophone, and the wider system includes buoy telemetry, environmental sensing, GPS/location, and system health data. Data is collected on a Raspberry Pi and uploaded to cloud storage, then processed for a web dashboard. The dashboard must feel technically credible, modern, clean, scientific, and presentation-ready.
